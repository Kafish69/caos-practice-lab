# CAOS Practice Lab

A free practice site for **CAOS – Computer Architectures & Operating Systems** (weeks 1.1–5.2).

**Open it:** https://kafish69.github.io/caos-practice-lab/

## What's inside

- **Mock test** – 15 multiple choice + 8 fill in the blanks + 6 commands + 4 calculations, randomized every time, 45-minute timer, per-topic score breakdown
- **Quiz** – 221 questions with instant explanations
- **Fill in the blanks** – 88 command, option and concept questions
- **Flashcards** – 120 cards
- **Command drill** – 98 tasks: read what to do, type the full command (alternative correct forms are accepted)
- **Binary · Hex · chmod** – endless random questions: decimal/binary/hex, chmod numbers and rwx, slack space, cluster counts, DDR transfer speed

## Topics (15)

Navigation & files · Viewing & searching · Inodes & links · Permissions · Users & groups · Forensics · Docker, WSL & other · Theory · Virtualization (hypervisors, VMware, NAT/bridged, snapshots/clones) · Shell & text tools (wildcards, history, redirection, sort/uniq/cut/awk/sed, regex) · Hardware & architecture (Von Neumann, Harvard, RISC/CISC, drivers) · CPU, memory & storage (instruction cycle, registers, cores, DDR, SSD/HDD, clusters) · File systems & RAID · Security & BIOS (POST, UEFI, /etc/passwd, salt, special permissions, SELinux)

Made from the course slides and a Linux command reference. Everything runs in the browser in one `index.html` file. Nothing is sent anywhere.

Good luck on the exam.
