# CAOS Practice Lab

A free practice site for **CAOS – Computer Architectures & Operating Systems**: Linux commands and theory.

**Open it:** https://kafish69.github.io/caos-practice-lab/

## What's inside

- **Mock test** – 15 multiple choice + 8 fill in the blanks + 6 commands + 4 conversions, randomized every time, 45-minute timer, per-topic score breakdown
- **Quiz** – 78 questions with instant explanations
- **Fill in the blanks** – 42 command and option questions
- **Flashcards** – 52 cards covering every command and concept
- **Command drill** – 54 tasks: read what to do, type the full command (alternative correct forms are accepted)
- **Binary · Hex · chmod** – endless random conversions, permission numbers and slack-space questions

Topics: navigation and files, viewing and searching (grep, find), inodes and links, permissions (chmod, chown, sudo), users and groups, digital forensics (dd, losetup, fls, icat), Docker, file system, number systems and virtualization.

Everything runs in the browser in one `index.html` file. Nothing is sent anywhere.

Good luck on the exam.
